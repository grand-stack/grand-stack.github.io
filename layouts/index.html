quickstart

From zero to a running graph API.

You need Docker or Podman with compose, and Node 22 or later for the examples. Everything runs on your machine.

1

Clone the repos side by side

The umbrella repo holds the compose files; the others are built from its sibling folders.

mkdir grand-stack && cd grand-stack
git clone https://github.com/{{ $org }}/grandstack
git clone https://github.com/{{ $org }}/grandstack-server
git clone https://github.com/{{ $org }}/grandstack-web
2

Start the stack

Neo4j, the GraphQL server (with 152 films and 464 people loaded) and the web app.

cd grandstack
cp .env.example .env
docker compose up --build
3

Open the app

Search, filter, compare, and edit films and people at localhost:3000. The GraphQL endpoint and GraphiQL are at localhost:4000/graphql.

4

Query the API

Any GraphQL client works; curl will do.

curl -s localhost:4000/graphql -H 'content-type: application/json' \
  -d '{"query":"{ moviesConnection { totalCount } }"}'
5

Let an agent use it

Add the MCP server (read-only by default; needs the grandstack-agents repo beside the others) and connect Claude Code.

docker compose -f compose.yaml -f compose.agents.yaml up --build
claude mcp add --transport http grandstack http://localhost:4100/mcp

Then go further

Add login, federate Wikipedia data into the graph, or build your own app on your own data.
