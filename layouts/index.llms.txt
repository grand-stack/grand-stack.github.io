# GRANDstack

> GraphQL on Neo4j, for developers and agents. A Neo4j graph, a GraphQL API generated from one schema file (@neo4j/graphql v7 on GraphQL Yoga), a typed React app, and an MCP server so agents can use the same API. Small repositories you can clone and run in Docker. Opt-in layers: auth (Keycloak and a gateway), agents (MCP), federation (a Wikipedia subgraph). The default stack has no authentication: run it locally and do not expose it. Licensed Apache-2.0.
